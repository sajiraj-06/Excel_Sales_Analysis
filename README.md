# Excel_Sales_Analysis
Retail Sales Data Analysis using Microsoft Excel

Retail Sales Data Analysis – Excel Portfolio Project

Project Overview

This project focuses on analyzing a retail sales dataset containing 1,000 records using Microsoft Excel. The objective is to identify sales trends, evaluate business performance, and generate meaningful insights to support data-driven decision-making.

Tools Used

- Microsoft Excel
- PivotTables
- PivotCharts
- Excel Formulas
- Slicers
- Data Cleaning and Validation

Project Objectives

- Clean and validate raw retail sales data.
- Identify and document data quality issues.
- Analyze revenue, profit, products, categories, and regions.
- Calculate key performance indicators (KPIs).
- Develop an interactive Excel dashboard.
- Provide actionable business recommendations.

Data Cleaning and Preparation

The project includes:

- Duplicate Order ID identification and handling.
- Missing Customer ID identification.
- Customer name and city standardization.
- Data validation for dates and numerical values.
- Identification of negative and unusual values.
- Creation of a cleaned dataset while preserving the original raw data.

Values requiring business confirmation were flagged rather than changed without evidence.

Key Performance Indicators (KPIs)

- Total Orders
- Total Revenue
- Total Profit
- Average Order Value
- Distinct Customer ID Values (including the Unknown placeholder)
- Average Customer Rating

Dashboard Analysis

The Excel dashboard includes:

1. Product-wise Revenue Analysis
2. Category-wise Revenue Analysis
3. Region-wise Revenue Analysis
4. Payment Method Analysis
5. Order Status Analysis

Interactive slicers are included for filtering and exploring the data.

Key Business Insights

- Electronics Dominates Revenue: Electronics generated LKR 102,927,700, representing approximately 72.95% of total revenue.
- Order Fulfillment: 765 out of 1,000 orders were completed, representing 76.5%.
- Regional Performance: Eastern and Central regions showed relatively balanced revenue performance.

Business Recommendations

- Focus on high-performing electronics products.
- Investigate pending, returned, and cancelled orders.
- Identify successful regional strategies and apply them across other regions.
- Monitor profitability and customer satisfaction.

Conclusion

This project demonstrates practical data analysis skills using Microsoft Excel, including data cleaning, validation, PivotTable analysis, KPI development, dashboard creation, and business insight generation.
